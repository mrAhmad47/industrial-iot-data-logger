# Industrial IoT Data Logging System (ATmega328P)

## Overview
This project presents the design and implementation of an Industrial IoT data logging system using the ATmega328P microcontroller. The system collects sensor data and logs it for monitoring and analysis.

The goal of the project was to develop a low-cost embedded system capable of monitoring environmental or industrial parameters and storing the collected data for further processing.

## Technologies Used
- ATmega328P Microcontroller
- Arduino Development Environment
- Embedded C Programming
- Sensors and Data Logging
- Embedded System Design

## System Features
- Real-time data acquisition from sensors
- Microcontroller-based data processing
- Data logging for monitoring applications
- Low-cost embedded hardware implementation
